# Project 01：STM32 数字电压表

## 项目目的

把 C 语言、STM32、ADC、显示和测量仪器第一次串起来。

## 系统链路

```text
输入电压
  ↓
分压/保护
  ↓
ADC
  ↓
数字滤波
  ↓
电压换算
  ↓
OLED/LCD
  ↓
串口输出
```

## 第一版功能

- ADC 单通道采样
- 计算平均值
- 显示电压
- UART 输出

## 第二版功能

- 定时器触发 ADC
- ADC + DMA
- 滑动平均/中值滤波
- 最大值/最小值
- 超量程提示

## 第三版功能

- 多量程
- 校准系数
- 采样率配置
- 数据记录
- PC 端数据可视化

## 必须学习

- ADC 分辨率
- 参考电压
- 分压电路
- 采样频率
- DMA
- 定点/浮点计算
- 误差分析
