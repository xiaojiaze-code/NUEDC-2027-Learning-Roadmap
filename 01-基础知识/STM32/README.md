# STM32 学习路线

> 目标：把 C 语言能力转化为电子设计竞赛中的真实硬件控制能力。

## 阶段 0：工具链

- [ ] STM32CubeMX / CubeIDE 或学校指定工具链
- [ ] Keil（如课程/实验室使用）
- [ ] ST-Link
- [ ] 串口工具
- [ ] Git 基础

## 阶段 1：GPIO

- [ ] 输出高低电平
- [ ] LED
- [ ] 按键
- [ ] 上拉/下拉
- [ ] 消抖

## 阶段 2：定时器

- [ ] 基本定时
- [ ] 输入捕获
- [ ] 输出比较
- [ ] PWM
- [ ] 测频
- [ ] 测脉宽

## 阶段 3：中断

- [ ] 外部中断
- [ ] 定时器中断
- [ ] UART 接收中断
- [ ] 中断与主循环共享变量
- [ ] `volatile`

## 阶段 4：通信

- [ ] UART
- [ ] I2C
- [ ] SPI
- [ ] CAN（了解）
- [ ] RS-485（了解）

## 阶段 5：ADC / DAC

- [ ] ADC 单通道
- [ ] 多通道扫描
- [ ] 定时器触发 ADC
- [ ] DMA
- [ ] 滤波
- [ ] 电压/电流换算
- [ ] DAC 输出

## 阶段 6：显示与人机交互

- [ ] OLED/LCD
- [ ] 按键
- [ ] 编码器
- [ ] 菜单状态机

## 阶段 7：电机与执行器

- [ ] PWM 控速
- [ ] H 桥
- [ ] 编码器
- [ ] PID
- [ ] 舵机
- [ ] 步进电机

## 阶段 8：竞赛级数据采集

重点链路：

```text
传感器
  ↓
模拟调理
  ↓
ADC
  ↓
DMA
  ↓
RAM 缓冲区
  ↓
数字滤波 / FFT / 参数估计
  ↓
控制算法
  ↓
PWM / DAC / 通信 / 显示
```

## 推荐实战顺序

1. LED + 按键
2. 定时器数字时钟
3. PWM 呼吸灯
4. UART 命令终端
5. ADC 电压表
6. ADC + DMA 数据采集
7. PWM + 电机
8. 编码器测速
9. PID 控制
10. FFT/频率测量

## 验收标准

最终必须做到：

> 给你一块陌生 STM32 开发板，你能在一天内完成 GPIO、定时器、UART、ADC/PWM 等基础外设的验证，并能使用示波器验证波形。
