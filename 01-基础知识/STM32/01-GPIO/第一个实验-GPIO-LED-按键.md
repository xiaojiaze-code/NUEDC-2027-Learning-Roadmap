# STM32 第一个实验：GPIO / LED / 按键

> 目标：建立 MCU 最基本的输入、输出、时序和调试能力。

## 实验目标

完成一个最小系统：

- LED 周期闪烁
- 按键控制 LED
- 长按/短按可区分（进阶）
- 串口打印状态（进阶）

## 必须理解

### GPIO

- 输入 / 输出
- 推挽 / 开漏
- 上拉 / 下拉
- 高低电平
- GPIO 初始化

### 按键

机械按键存在抖动，不能简单地认为“一次按下只产生一次电平变化”。

建议先掌握：

1. 延时消抖
2. 定时采样消抖
3. 状态机消抖

## 最小程序结构

```c
int main(void)
{
    HAL_Init();
    SystemClock_Config();
    MX_GPIO_Init();

    while (1)
    {
        HAL_GPIO_TogglePin(LED_GPIO_Port, LED_Pin);
        HAL_Delay(500);
    }
}
```

> 如果使用其他 HAL/LL/标准库，API 会不同；重点是理解 GPIO 寄存器和驱动层的关系，不要死记函数名。

## 验收
