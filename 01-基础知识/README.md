# 基础知识地图

这里是整个仓库的知识树。学习时不要按教材顺序机械推进，而要围绕竞赛能力建立连接。

## A. 电路基础

- 基本电路定律：欧姆、KCL、KVL
- 节点/回路分析
- 戴维南/诺顿等效
- 一阶/二阶暂态
- 交流稳态、相量
- 阻抗与功率

## B. 模拟电子技术

- 二极管、BJT、MOSFET
- 理想与实际运放
- 反馈
- 放大器
- 比较器
- 整流/检波
- 有源滤波器
- 电源与功率器件

## C. 数字电子技术

- 逻辑门
- 组合逻辑
- 时序逻辑
- 触发器
- 计数器
- 状态机
- ADC/DAC 接口

## D. 嵌入式

- C 语言
- MCU 架构基础
- STM32 GPIO/Timer/UART/SPI/I2C/ADC/DMA/DAC
- 中断
- 状态机
- 定时与实时性
- 调试

## E. 信号与 DSP

- 采样定理
- 离散信号
- FFT
- FIR/IIR
- 频谱分析
- 数字解调基础

## F. 控制

- 反馈
- PID
- PWM
- 电机控制
- 传感器采集
- 稳态/动态指标

## G. 工程实践

- 示波器
- 信号发生器
- 万用表
- 直流电源
- 逻辑分析仪
- 焊接
- PCB
- 接地、去耦、噪声与 EMI 基础

每个知识点最终都要进入“理论 → 仿真 → 实验 → 项目 → 真题”的闭环。
