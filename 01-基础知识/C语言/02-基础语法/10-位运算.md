# 10 位运算：嵌入式 C 的核心工具

## 必须掌握

- `&` 按位与
- `|` 按位或
- `^` 按位异或
- `~` 按位取反
- `<<` 左移
- `>>` 右移
- 掩码（mask）
- 置位、清零、翻转、读取某一位

## 四个基本模板

### 置 1

```c
reg |= (1U << n);
```

### 清 0

```c
reg &= ~(1U << n);
```

### 翻转

```c
reg ^= (1U << n);
```

### 读取

```c
if (reg & (1U << n)) {
    // bit n = 1
}
```

## 为什么国赛需要

GPIO、寄存器配置、状态标志、通信协议字段、ADC/DAC 数据处理、编码数据等都会大量使用位运算。

## 必做练习

1. 写 `set_bit()`、`clear_bit()`、`toggle_bit()`、`read_bit()`。
2. 用一个 `uint8_t` 保存 8 个开关状态。
3. 把四个 4-bit 数据打包到一个 16-bit 整数中，再解包。
4. 解析一个自定义通信帧：帧头 + 地址 + 数据 + 校验。
