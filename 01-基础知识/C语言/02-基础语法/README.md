# C 语言基础语法

> 目标：把“会写 C”提升到“能用 C 写可靠的嵌入式程序”。

## 学习顺序

1. 变量与数据类型
2. 运算符与表达式
3. 条件语句
4. 循环
5. 函数
6. 数组
7. 字符串
8. 指针
9. 结构体与枚举
10. 位运算
11. 预处理与宏
12. 文件与模块化

## 每一阶段必须完成

- 能解释核心概念，而不是只背语法
- 能独立写 3~5 个小程序
- 能读懂陌生代码
- 能定位至少一类常见 Bug
- 能说明这个知识点在 STM32/电子设计竞赛中的用途

## 竞赛优先级

### S 级：必须熟练

- 函数
- 数组
- 指针
- 结构体
- 位运算
- 宏
- `const`
- `static`
- `volatile`

### A 级：必须掌握

- 字符串
- 枚举
- 预处理
- 模块化编程
- 头文件与源文件
- 调试

### B 级：理解即可

- 文件 I/O
- 动态内存的基础使用
- 复杂的标准库细节

嵌入式阶段会重新学习其中与硬件相关的部分。
