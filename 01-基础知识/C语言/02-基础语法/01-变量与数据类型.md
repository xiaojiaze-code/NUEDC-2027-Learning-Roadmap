# 01 变量与数据类型

## 1. 必须掌握

- 整型：`char`、`short`、`int`、`long`、`long long`
- 无符号类型：`unsigned`
- 浮点型：`float`、`double`
- 布尔：`bool`（需要 `<stdbool.h>`）
- 常量：`const`
- 类型转换
- `sizeof`

## 2. 嵌入式最重要的认知

不要只记“int 是 4 字节”。C 标准并不保证所有平台的具体字节数；应使用 `sizeof`，并在 MCU 工程中明确数据宽度。

推荐建立这种意识：

```c
uint8_t  // 8 bit
uint16_t // 16 bit
uint32_t // 32 bit
int32_t  // 32 bit 有符号整数
```

这些类型通常来自 `<stdint.h>`，在嵌入式工程中比含糊的基础类型更适合表达硬件寄存器、协议字段和采样数据。
