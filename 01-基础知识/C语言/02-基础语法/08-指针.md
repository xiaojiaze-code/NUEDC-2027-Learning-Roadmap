# 08 指针：C 语言与嵌入式的分水岭

## 为什么必须学透

STM32 程序会频繁接触：

- 数组首地址
- 缓冲区
- 函数参数传递
- 字符串
- 外设寄存器
- DMA 数据缓冲
- 结构体指针
- 回调函数

如果指针只会“背 `*` 和 `&`”，进入 STM32 后会非常痛苦。

## 1. 第一层：地址与取值

```c
int x = 10;
int *p = &x;

printf("%d\\n", *p);
```

理解：

- `&x`：得到变量地址
- `p`：保存地址
- `*p`：访问该地址对应的对象

## 2. 第二层：指针与数组

数组名在多数表达式中会转换为指向首元素的指针。

```c
int a[4] = {1, 2, 3, 4};
int *p = a;

printf("%d\\n", *(p + 2));
```

必须真正理解：

`p + 1` 不是地址简单加 1，而是前进一个元素的大小。

## 3. 第三层：指针作为函数参数

这是嵌入式最常用的模式之一。

```c
void adc_process(uint16_t *buffer, uint16_t length)
{
    // 处理采样缓冲区
}
```

调用者可以把一块采样数据交给函数处理，而不必复制整个数组。

## 4. 第四层：结构体指针

```c
typedef struct {
    float kp;
    float ki;
    float kd;
} PID_t;

PID_t pid;
PID_t *p = &pid;
p->kp = 1.0f;
```

`p->kp` 等价于 `(*p).kp`。

## 5. 第五层：函数指针

了解即可，后续用于回调、驱动接口和状态机。

```c
void callback(void)
{
}

void (*fp)(void) = callback;
fp();
```

## 高频错误

- 野指针
- 空指针解引用
- 越界访问
- 返回局部变量地址
- 指针类型不匹配
- 把数组和指针完全等同
- 忽略 `const`
