# 嵌入式 C

> 目标：从“桌面 C 程序”过渡到“控制 MCU 的 C 程序”。

## 核心主题

1. `const`：只读数据与接口约束
2. `static`：生命周期、文件作用域与模块封装
3. `volatile`：告诉编译器变量可能被异步改变；常见于硬件寄存器、中断共享变量等场景
4. `stdint.h`：明确整数宽度
5. 指针与内存映射
6. 结构体与设备对象
7. 位运算与寄存器
8. 状态机
9. 环形缓冲区
10. 回调函数
11. 模块化驱动
12. 中断安全与共享数据
13. 固定长度缓冲区与边界检查
14. 调试与日志

## 推荐代码结构

```text
Core/
├── Inc/
│   ├── app.h
│   └── sensor.h
└── Src/
    ├── app.c
    └── sensor.c
```

原则：

- `.h` 放接口、类型和必要宏
- `.c` 放实现
- 尽量减少全局变量
- 模块之间通过明确接口通信
- 驱动层与业务层分离

## 竞赛重点

### S 级

- 指针
- `volatile`
- 位运算
- 状态机
- 数组/缓冲区
- 中断与主循环协作

### A 级

- 回调
- 环形队列
- 模块化
- 错误码
- 参数校验

## 必做项目

### 项目 1：串口命令解析器

实现：

`SET PWM 50` → 修改 PWM 占空比

`GET ADC` → 返回当前 ADC 值

### 项目 2：环形缓冲区

实现 UART 接收缓冲，支持写入、读取、判断满/空。

### 项目 3：有限状态机

实现一个按键控制的设备状态机：`IDLE → RUN → ERROR → IDLE`。

### 项目 4：传感器驱动框架

设计统一接口，让多个传感器都能提供 `init()`、`read()`、`calibrate()`。

## 终点标准

你应该能够在没有复制粘贴的情况下写出一个结构清晰的 STM32 小项目，而不是把所有代码塞进 `main.c`。
