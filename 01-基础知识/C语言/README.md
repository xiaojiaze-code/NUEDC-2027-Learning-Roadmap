# C语言完整学习路径

> 目标：不是为了考一张 C 语言试卷，而是把 C 语言练成参加全国大学生电子设计竞赛所需的**嵌入式编程工具**。

## 一、最终能力目标

完成本路线后，应能独立完成：

- 用 C 写出结构清晰、可维护的中小型程序
- 熟练使用变量、数组、指针、结构体、函数、枚举、位运算
- 阅读并修改 STM32 工程中的 HAL/LL 外设代码
- 编写 GPIO、定时器、PWM、ADC、UART、SPI、I2C 等驱动逻辑
- 使用中断、DMA、环形缓冲区处理实时数据
- 根据数据手册完成寄存器/位域级代码阅读
- 定位常见的内存、数组越界、指针、时序和逻辑错误
- 将一个竞赛需求拆成模块、接口和状态机

## 三、学习原则

### 1. 代码优先

建议每学习一个知识点，都完成：

**看懂 → 手写 → 修改 → 调试 → 独立实现**。

只看视频、复制代码、背语法，不算掌握。

### 2. 从第一天养成嵌入式习惯

优先掌握：

- `stdint.h` 中的 `uint8_t`、`uint16_t`、`uint32_t`、`int32_t`
- `const`
- `static`
- `volatile`
- 位运算
- 指针
- 结构体
- 枚举
- 宏
- 模块化接口

### 3. 不追求“学完 C 才开始 STM32”

C 基础达到能够独立写小程序后，就应该进入 STM32；之后边做硬件边补 C。

## 四、阶段详解

### 阶段0：编译、链接与调试基础

掌握：

- 源文件、头文件
- 预处理
- 编译
- 汇编
- 链接
- 可执行文件
- `gcc` 基本用法
- 编译警告
- Debug 与 Release 的基本区别

验收：能够解释 `.c → 预处理 → .s → .o → 可执行文件` 的基本过程，并能看懂常见编译错误。

---

### 阶段1：语法基础

掌握：

- 基本数据类型
- 变量与常量
- 运算符
- 类型转换
- `if / else`
- `switch`
- `for / while / do while`
- `break / continue`
- 输入输出

练习：

1. 温度单位转换
2. BMI 计算
3. 最大值/最小值
4. 素数判断
5. 排列与循环练习
6. 简单菜单程序

验收标准：不查资料独立写出 20 个基础小程序。

---

### 阶段2：函数、数组、字符串

掌握：

- 函数声明/定义/调用
- 参数与返回值
- 作用域
- 一维数组
- 二维数组
- 字符数组
- 字符串
- 常用字符串函数

重点：理解“数组作为函数参数传递”以及数组长度信息为什么不会自动传入函数。

竞赛关联：采样数据、查表数据、滤波缓存、通信缓冲区都会大量使用数组。

验收项目：

**数字滤波器基础模拟**：输入一组采样数据，计算滑动平均值，并输出原始数据和滤波数据。

---

### 阶段3：指针与内存 ★★★★★

这是电子设计竞赛 C 语言最重要的部分之一。

掌握：

- 地址与指针
- 指针声明与解引用
- 指针与数组
- 指针与函数
- 指针数组
- 数组指针
- 二级指针
- `NULL`
- `const` 与指针
- 静态存储区、栈、堆的基本概念
- `malloc/free` 基本原理
- 野指针
- 悬空指针
- 越界访问

嵌入式重点：理解为什么 STM32 工程里大量 API 使用指针传递数据和结构体。

验收：能够解释并正确完成“函数修改调用者变量”“数组传参”“结构体指针访问”等任务，并能定位常见段错误/非法访问原因。

---

### 阶段4：结构体、枚举、联合体、位运算 ★★★★★

掌握：

- `struct`
- `typedef`
- `enum`
- `union`
- 位与 `&`
- 位或 `|`
- 异或 `^`
- 取反 `~`
- 左移/右移
- 位掩码
- 寄存器位操作

竞赛关联：

```c
REG |=  (1u << 3);   // 置位
REG &= ~(1u << 3);   // 清零
REG ^=  (1u << 3);   // 翻转
if (REG & (1u << 3)) // 判断
```

验收项目：实现一个“虚拟 GPIO 寄存器”，用位运算完成端口配置、置位、清零、翻转和读取。

---

### 阶段5：预处理与模块化

掌握：

- `#include`
- `#define`
- 条件编译
- 头文件保护
- `extern`
- `static`
- 多文件工程
- `.h/.c` 模块划分

目标：从“一个 main.c 写到底”升级为：

```text
main.c
bsp_led.c / .h
bsp_key.c / .h
bsp_uart.c / .h
filter.c / .h
motor.c / .h
```

这是从学生代码向工程代码迈出的关键一步。

---

### 阶段6：数据结构与算法

不需要把计算机专业算法全部学完，但以下必须会：

- 顺序查找
- 二分查找
- 冒泡/选择/插入排序
- 栈
- 队列
- 环形队列
- 链表基础
- 状态机
- 简单递归
- 时间复杂度的基本概念

**重点不是刷算法题，而是解决竞赛中的数据处理问题。**

---

### 阶段7：嵌入式 C

重点进入 MCU 思维：

- `volatile`
- 中断共享变量
- 定时器节拍
- 软件延时与硬件定时
- GPIO 抽象
- 状态机
- 环形缓冲区
- 非阻塞程序
- 看门狗
- 错误处理
- 模块接口设计

必须逐渐避免：

```c
while(1) {
    delay_ms(1000);
    // 一大坨代码
}
```

转向：

```c
while (1)
{
    Key_Task();
    Sensor_Task();
    Control_Task();
    Communication_Task();
    Display_Task();
}
```

---

### 阶段8：STM32 C 编程

推荐学习顺序：

1. GPIO
2. EXTI
3. Timer
4. PWM
5. UART
6. ADC
7. DMA
8. I2C
9. SPI
10. 输入捕获
11. 编码器接口
12. DAC

每一个外设都按照：

**原理 → 配置 → API → 中断/DMA → 实验 → 封装模块 → 综合项目**。

---

### 阶段9：竞赛级 C

最终需要掌握：

- ADC + DMA 采样
- 定时器触发采样
- UART/SPI/I2C 通信
- PWM 电机控制
- PID 控制代码
- FFT 前的数据采集与缓存
- 环形缓冲区
- 状态机
- 多模块协同
- 参数结构体
- 调试日志
- 故障保护

## 五、建议学习节奏

如果每周能稳定投入 8～12 小时：

| 周期 | 目标 |
|---|---|
| 第1-2周 | 语法基础 |
| 第3-4周 | 函数、数组、字符串 |
| 第5-7周 | 指针与内存 |
| 第8-9周 | 结构体、位运算 |
| 第10周 | 预处理与模块化 |

## 八、禁止踩的坑

- 只看教程不写代码
- 背语法不理解内存
- 过早依赖复制粘贴的 STM32 工程
- 不看编译器警告
- 滥用全局变量
- 用阻塞延时解决所有问题
- 不理解指针就开始大量复制驱动代码
- 把“程序能跑”误认为“程序正确”

## 九、最终目标

> **C 语言不是终点。C 语言是你控制 MCU、采集信号、驱动执行器、实现算法和完成电子系统的底层工具。**

因此，本路线完成后必须进入 STM32、模拟电路、数字电路、信号处理和仪器测量实战。
