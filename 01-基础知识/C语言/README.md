# C语言训练区

这里不是为了应付 C 语言考试，而是为了服务 **STM32 + 电子设计竞赛**。

## 学习顺序

1. 变量、数据类型、运算符
2. 条件、循环、函数
3. 数组、字符串
4. 指针
5. 结构体、枚举、联合体
6. 位运算
7. 预处理、头文件、模块化
8. 内存、栈、堆、生命周期
9. `const` / `static` / `volatile`
10. 函数指针与回调
11. 环形缓冲区与状态机
12. 嵌入式 C

## 通过标准

不要只看懂。每个章节至少完成：

- 手写 3 个小程序
- 独立解释关键代码
- 能定位 1 个常见 bug
- 能把知识迁移到 MCU 场景

## 竞赛重点

⭐⭐⭐⭐⭐ 指针、数组、结构体、位运算、`volatile`、状态机、模块化

⭐⭐⭐⭐ ADC 数据处理、串口协议、环形缓冲区、定时任务

⭐⭐⭐ 文件/标准库高级特性

## 推荐练习

- ADC 数据平均值、最大值、最小值
- 按键消抖状态机
- 环形串口接收缓冲区
- PWM 占空比计算
- 简单菜单系统
- 传感器数据滤波

## 验收问题

如果不能回答“为什么这里用 `uint32_t` 而不是 `uint16_t`”“为什么中断共享变量通常需要 `volatile`”，说明还没有真正掌握。
