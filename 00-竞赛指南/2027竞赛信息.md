# 2027 全国大学生电子设计竞赛信息

## 重要说明

本文件只记录已经确认的信息和待官方确认的信息。

### 已确认的长期背景

- 全国大学生电子设计竞赛（NUEDC）始于 1994 年。
- 竞赛通常按奇数年举办，2025 年为第十七届，因此 2027 年预计进入下一届周期。
- 2027 年具体比赛日期、题目、当届规则、报名时间、赛区安排等，必须以当届官方通知为准。

## 2027 备赛倒计时策略

在官方赛题发布前，不猜题，重点训练通用能力：

1. C 语言与嵌入式 C
2. STM32 外设与调试
3. 模拟电子技术
4. 数字电子技术
5. ADC/DAC/采样与滤波
6. PWM、定时器、DMA
7. UART/SPI/I2C/CAN 等通信
8. 运放、功率器件与电源
9. 示波器、信号源、万用表
10. PCB、焊接、可靠性与故障定位
11. 控制算法与 DSP
12. 历届真题的系统拆解

## 比赛思维

不要把竞赛理解成“单片机比赛”。真正的工程链条是：

**需求 → 指标 → 系统方案 → 理论计算 → 器件选型 → 电路 → PCB/搭建 → 软件 → 联调 → 测试 → 指标优化 → 报告。**

2027 具体规则发布后，应立即更新本文件，并在提交记录中注明官方来源和日期。
