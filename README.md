# NUEDC-2027-Learning-Roadmap

> 肖佳泽的 2027 全国大学生电子设计竞赛（NUEDC）学习与训练基地

本仓库不是单纯的资料收藏夹，而是一套从**零基础 → 模块能力 → 综合项目 → 历届真题 → 赛前模拟 → 竞赛复盘**的长期训练系统。

## 🎯 目标

- 建立电子设计竞赛所需的系统知识结构
- 掌握 C / STM32 / 模拟电路 / 数字电路 / 信号处理 / 控制 / 通信 / PCB / 测量调试
- 通过可验证的实验和项目，而不是只看教程，形成真正的工程能力
- 在 2027 国赛前完成至少 6 个模块项目 + 3 个综合项目 + 多套历届真题拆解
- 最终把竞赛项目沉淀为可展示的 GitHub 工程作品集

## ⚠️ 关于 2027 竞赛信息

2027 年具体赛题、正式竞赛日期、命题范围和通知，以全国大学生电子设计竞赛官方发布为准。本仓库不会把尚未正式公布的信息伪装成确定事实。

竞赛历史资料显示，竞赛自 1994 年开始，此后通常逢奇数年举办；截至 2025 年已有第十七届资料。2025 年竞赛每队严格 3 人，比赛期间可使用图书资料和网络资源，但制作必须在指定竞赛场地内完成，具体规则以当届正式文件为准。

## 🏆 训练原则

1. **先做再补理论**：遇到真实问题时补知识，避免只刷课程。
2. **每个知识点必须有验收标准**：会解释、会计算、会仿真、会实测、会排错。
3. **优先掌握高频能力**：ADC、PWM、定时器、DMA、UART/SPI/I2C、运放、滤波、采样、控制、测量。
4. **工程能力优先于代码炫技**：竞赛的核心是可靠地完成指标。
5. **记录每一次失败**：故障现象、假设、测量、定位、修改、结果全部记录。
