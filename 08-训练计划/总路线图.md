# 总路线图：从现在到 2027 国赛

## Phase 0：环境与基础（2–4 周）

目标：建立最小工程能力。

- C 语言：变量、指针、数组、结构体、函数、位运算、模块化
- 电路：欧姆定律、KCL/KVL、RC/RL、戴维南/诺顿
- 数字电路：逻辑门、触发器、计数器、状态机
- Git/GitHub：commit、branch、README、实验记录

验收：能独立写小型 C 程序；能读懂基础原理图；能用万用表完成基本测量。

## Phase 1：STM32 核心能力（4–8 周）

必须掌握：

- GPIO
- EXTI
- Timer
- PWM
- UART
- SPI
- I2C
- ADC
- DMA
- DAC
- RTC/看门狗等常用外设

验收：能够从数据手册/参考手册定位寄存器或 HAL 配置；能独立调试一个外设链路。

## Phase 2：模拟 + 测量（4–8 周）

- 运算放大器
- BJT/MOSFET
- 放大器
- 有源/无源滤波器
- 比较器
- 整流与检波
- 稳压与 DC-DC 基础
- ADC 前端
- 噪声、接地、供电、去耦
- 示波器/信号发生器/万用表

验收：给定输入与指标，能设计并测量一个实际模拟电路。

## Phase 3：信号处理与控制（4–8 周）

- 采样定理
- FFT
- 数字滤波
- 频率/幅值/相位测量
- PID
- PWM 控制
- 电机基础
- 传感器融合基础

验收：能够把 ADC 采样数据送入算法，再输出稳定、可测量的控制结果。

## Phase 4：PCB + 工程化（持续）

- 原理图规范
- PCB 布局布线
- 电源与地
- 模拟/数字分区
- 接插件与机械结构
- 焊接返修
- BOM
- 版本管理
- 故障定位

验收：做出一块可以稳定运行的自己的 PCB，并能复现和定位常见故障。

## Phase 5：模块项目

建议至少完成：

1. 数字电压表
2. 频率计
3. 函数信号发生器
4. 温度/光照采集系统
5. 电机闭环控制
6. 无线通信节点
7. 简易数字示波/波形采集系统

## Phase 6：历届真题

每道真题按照以下模板拆：

**题目 → 指标 → 难点 → 系统框图 → 理论 → 器件 → 软件 → 调试风险 → 得分点 → 可复用模块。**

## Phase 7：模拟赛

逐渐从 24 小时、16 小时、12 小时训练到完整赛制模拟。重点不是“做完”，而是：

- 快速读题
- 方案决策
- 模块复用
- 风险控制
- 指标分层
- 测试记录
- 报告同步编写

## 最终能力标准

达到以下状态才算进入真正的竞赛准备阶段：

> 面对陌生题目，能够在 1–2 小时内提出可落地系统方案；能够迅速识别关键指标和高风险模块；能够用已有模块快速搭建原型；能够通过仪器定位问题；能够持续优化指标。
