# 2026-09：第一个月训练计划

> 本月不是冲刺真题，而是建立能参加竞赛的最低硬件软件基础。

## Week 1：C语言 + 电路

- C：变量、运算符、条件、循环、函数
- 电路：欧姆定律、功率、KCL、KVL、分压
- 练习：每天 2~3 道 C 题
- 实验：万用表测电阻、电压、电流

## Week 2：数组、指针 + RC

- C：数组、字符串、指针
- 电路：RC 一阶电路、时间常数
- 实验：观察 RC 充放电
- 验收：能解释指针和数组的关系

## Week 3：STM32 GPIO + Timer

- GPIO 输入输出
- 按键消抖
- 定时器基本概念
- PWM
- 实验：LED、按键、1 kHz PWM

## Week 4：ADC + UART

- ADC 分辨率、参考电压、采样时间
- UART 基础
- ADC 数据换算
- 实验：串口输出 ADC 电压

## 本月最终作品

完成一个“**STM32 简易数字电压表**”：

ADC 采集 → 数据处理 → 电压换算 → 串口显示。

## 本月禁止的低效行为

- 只看视频不敲代码
- 复制工程但不知道每个模块作用
- 只在仿真软件里做实验
- 不记录实测数据

## 月末验收

必须能从零解释并复现：

`GPIO → Timer → ADC → UART → 数据处理`

如果不能独立完成，就不要急着进入复杂真题。
